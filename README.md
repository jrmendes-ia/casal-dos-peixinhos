# Casal dos Peixinhos

Website estático bilingue PT/EN para GitHub Pages.

## Publicar
1. Carregar o conteúdo desta pasta (não a pasta em si) para a raiz do repositório `jrmendes-ia/casal-dos-peixinhos`.
2. Em **Settings → Pages**, selecionar **Deploy from a branch**, branch `main`, pasta `/ (root)` e guardar.
3. Antes de ativar o domínio personalizado, configurar DNS no fornecedor do domínio conforme as instruções atuais do GitHub Pages. O ficheiro `CNAME` já contém `casaldospeixinhos.pt`.
4. Ativar HTTPS quando estiver disponível.

## Importante
- O formulário atual abre a aplicação de email do visitante (mailto). Para envio automático, será necessário integrar um serviço de formulários.
- As simulações são identificadas como conceptuais; fotografias de obras não significam infraestruturas concluídas.
- Os três vídeos recebidos não estão incluídos nesta primeira versão, para manter o carregamento e a publicação simples.
- Rever todos os dados comerciais e documentais antes de publicar.
